Hi! I’m Shohibun Najam Ilma, a software developer working across web, mobile, and desktop application development.

With a strong foundation in frontend development, I enjoy transforming ideas and UI/UX designs into responsive, interactive, and maintainable applications. I also work with REST APIs and backend services to connect user interfaces with application functionality.

Currently, I’m working as a Full Stack Developer at PT. Senyum Media Utama, contributing to web and mobile application development.

What I Do

* 🖥️ Desktop Development — Exploring desktop application development with Electron and Tauri.
* 🎨 UI Engineering — Creating responsive interfaces, reusable components, and engaging interactions.
* 🔌 API Integration — Connecting frontend applications with REST APIs and backend services.
* 🚀 Development Workflow — Managing source code, collaboration, and deployment with Git, GitHub, and modern hosting platforms.

I enjoy exploring new technologies, solving practical problems, and building digital products that balance functionality, usability, and visual quality.
